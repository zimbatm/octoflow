Every GitHub event of an organization, as a live stream.

Octoflow stores the webhook events of the organizations that send them here, and serves them over Server-Sent Events. You can follow everything, or one repository, user, pull request or issue. No key is necessary. Look at the data below, then copy the snippet for the stream you see.

  • -events stored
  • -events in the last minute, this stream
  • -open streams on this server

        Use this stream

        
            
          
                
        • Each message is one JSON object: event, action, repository, sender and the full GitHub payload.
          • 
                
        • last=N replays the last N events of the stream before new ones, 1000 at most.
          • 
                
        • A browser that reconnects continues where it stopped. Other clients send Last-Event-ID with the last id they read.
          • 
                
        • The paths use numeric GitHub ids, so a renamed repository keeps its stream.
          • 
            
        
        
        
    
        

        


        
    
        Routes and fields
        
    
        All routes answer GET with text/event-stream and permit requests from any origin.
       The SSE API reference
       and the event format have the details.
        
    
        
        
        
            
        
                
        RouteEvents
        
                
                    
        /eventseverything, one time each
        
                    
        /events/org/{org_id}one organization
        
                    
        /events/repo/{repo_id}one repository
        
                    
        /events/user/{user_id}events that involve one user: sender, author, assignee, reviewer
        
                    
        /events/pr/{repo_id}/{number}one pull request and its reviews
        
                    
        /events/issue/{repo_id}/{number}one issue and its comments
        
                    
        /events/type/{event_type}one GitHub event type, for example push
        
                    
        ?last=Nreplay before the live events; default 50, 0 for none
        
                    
        ?type=a,b ?action=x,ykeep only these event types or actions
        
                    
        /statsJSON: stored events and open streams
        
                        
            
        
        
        
        
        
            
        
                
        FieldMeaning
        
                
                    
        idthe delivery id of GitHub
        
                    
        event, actionthe GitHub event type and its action, for example pull_request and opened
        
                    
        received_atwhen Octoflow received it, UTC
        
                    
        repository, repository_idfull name and numeric id
        
                    
        organization, organization_idlogin and numeric id
        
                    
        sender, sender_idthe user that caused the event
        
                    
        payloadthe GitHub webhook payload, not changed.
                        GitHub documents each type.
